     1→# Skill: Netlify Free Tier Maxxing for Scraping & Background Compute
     2→
     3→> **Load this file at the start of any dev session that involves building scrapers, data pipelines, or background compute on Netlify's free tier.** All findings below are hands-on validated as of 2026-08-14 against a real Netlify credit-based Free account.
     4→
     5→## When to use this skill
     6→
     7→Use this skill when the user wants to:
     8→- Build a scraper / crawler / data pipeline that runs on free infrastructure
     9→- Use Netlify's build process as free compute (cron-style background jobs)
    10→- Store scraped/processed data without paying for storage
    11→- Run headless Chrome (Puppeteer) for free for JS-rendered scraping
    12→- Maximize Netlify's free tier for any I/O-bound or CPU-light workload
    13→- Compare Netlify free tier with Cloudflare/Supabase for a specific use case
    14→
    15→**Do NOT use this skill if:**
    16→- The user needs a production web app with custom domains and high traffic (just pay for Pro)
    17→- The user needs a database with low-latency reads (use Supabase/Neon instead)
    18→- The user needs serverless functions invoked by HTTP requests at scale (use Cloudflare Workers)
    19→
    20→## TL;DR — The Free Paths
    21→
    22→1. **Preview deploys (`draft: true` or `netlify deploy` without `--prod`) = 0 credits. Always.**
    23→2. **Netlify Blobs = unmetered storage. Write/read any volume. 0 credits. Verified 12+ MB transfers.**
    24→3. **Build process = 15 min free compute per preview deploy. 2 vCPU, 4 GB RAM, 9 GB disk, outbound HTTP, npm install. Can run headless Chrome via `@sparticuz/chromium`.**
    25→4. **Build plugin `onPostBuild` = the only phase with `NETLIFY_BLOBS_CONTEXT` env var. Build command phase does NOT have it. Write data to `/tmp/` in build command, plugin reads `/tmp/` and stores to Blobs.**
    26→5. **One Free team per Netlify user (hard API-enforced). Supabase-style per-org rotation does NOT work.**
    27→
    28→## Hard Rules — Never Violate
    29→
    30→### 🚫 Never use `--prod` flag
    31→```bash
    32→netlify deploy --prod    # ❌ COSTS 15 CREDITS PER DEPLOY
    33→netlify deploy            # ✅ 0 CREDITS (preview deploy)
    34→```
    35→
    36→### 🚫 Never call `POST /sites/{id}/deploys` without `draft: true`
    37→```bash
    38→# ❌ Creates production deploy context (15 credits when ready)
    39→curl -X POST "https://api.netlify.com/api/v1/sites/{id}/deploys" \
    40→  -H "Authorization: Bearer $TOKEN" \
    41→  -d '{"files":{...}}'
    42→
    43→# ✅ Creates preview deploy (0 credits)
    44→curl -X POST "https://api.netlify.com/api/v1/sites/{id}/deploys" \
    45→  -H "Authorization: Bearer $TOKEN" \
    46→  -d '{"draft":true,"files":{...}}'
    47→```
    48→
    49→### 🚫 Never write a single multi-MB string to `process.stdout.write()` in builds
    50→Netlify's log ingester chokes. Use streaming via `readline` instead:
    51→```js
    52→// ❌ Will hang the build
    53→const bigData = readFileSync('/tmp/raw.jsonl', 'utf8');
    54→process.stdout.write(bigData);
    55→
    56→// ✅ Streams line-by-line, works fine
    57→import { createReadStream } from 'node:fs';
    58→import { createInterface } from 'node:readline';
    59→const rl = createInterface({ input: createReadStream('/tmp/raw.jsonl'), crlfDelay: Infinity });
    60→for await (const line of rl) process.stdout.write(line + '\n');
    61→```
    62→
    63→### 🚫 Don't expect build hooks to work without Git
    64→- `POST /build_hooks/{id}` returns HTTP 200 but doesn't trigger a build if site isn't Git-connected
    65→- Use `POST /sites/{id}/deploys` with `draft:true` + PAT instead
    66→
    67→### 🚫 Don't try to create multiple Free teams under one account
    68→- API returns `422 "Account plan is unavailable to this user"`
    69→- One Free team per Netlify user, hard-enforced server-side

    71→## How to Trigger a Free Preview Deploy
    72→
    73→### Option 1: Netlify CLI (simplest)
    74→```bash
    75→NETLIFY_AUTH_TOKEN=nfp_xxx netlify deploy --message "scrape run"
    76→# Output: Draft URL: https://<deploy-id>--<site-name>.netlify.app
    77→# State: ready, context: deploy-preview, credits: 0
    78→```
    79→
    80→### Option 2: Direct API (for cron / GitHub Actions)
    81→```bash
    82→# Step 1: Create draft deploy with file hashes
    83→DEPLOY_RESP=$(curl -s -X POST "https://api.netlify.com/api/v1/sites/$SITE_ID/deploys" \
    84→  -H "Authorization: Bearer $TOKEN" \
    85→  -H "Content-Type: application/json" \
    86→  -d "{\"draft\":true,\"files\":{\"/index.html\":\"$(sha1sum index.html | awk '{print $1}')\"}}")
    87→
    88→DEPLOY_ID=$(echo "$DEPLOY_RESP" | jq -r .id)
    89→
    90→# Step 2: Upload each file via presigned URL pattern
    91→curl -X PUT "https://api.netlify.com/api/v1/deploys/$DEPLOY_ID/files/index.html" \
    92→  -H "Authorization: Bearer $TOKEN" \
    93→  -H "Content-Type: application/octet-stream" \
    94→  --data-binary @index.html
    95→```
    96→
    97→### Option 3: GitHub Actions cron (recommended for production)
    98→```yaml
    99→# .github/workflows/scrape.yml
   100→name: Netlify Scrape
   101→on:
   102→  schedule:
   103→    - cron: '0 * * * *'  # hourly
   104→jobs:
   105→  trigger:
   106→    runs-on: ubuntu-latest
   107→    steps:
   108→      - run: |
   109→          curl -X POST "https://api.netlify.com/api/v1/sites/${{ secrets.NETLIFY_SITE_ID }}/deploys" \
   110→            -H "Authorization: Bearer ${{ secrets.NETLIFY_AUTH_TOKEN }}" \
   111→            -H "Content-Type: application/json" \
   112→            -d '{"draft":true,"title":"hourly-scrape","files":{}}'
   113→```

   141→### `src/scrape.js` (canonical template)
   142→```js
   143→import { writeFileSync, appendFileSync } from 'node:fs';
   144→
   145→const RAW_FILE = '/tmp/scrape-raw.jsonl';
   146→const PROCESSED_FILE = '/tmp/scrape-processed.json';
   147→const RUN_START = Date.now();
   148→const RUN_ID = `scrape-${RUN_START}`;
   149→
   150→console.log(`========== SCRAPE RUN ${RUN_ID} ==========`);
   151→console.log(`Started: ${new Date().toISOString()}`);
   152→
   153→writeFileSync(RAW_FILE, '');
   154→
   155→// === Scrape loop ===
   156→const items = []; // or stream directly to file
   157→for (const target of TARGETS) {
   158→  const r = await fetch(target.url);
   159→  const data = await r.json();
   160→  appendFileSync(RAW_FILE, JSON.stringify({...data, _target: target.id}) + '\n');
   161→  // Print progress to log (auditable)
   162→  if (items.length % 50 === 0) {
   163→    console.log(`  Fetched ${items.length} items | ${(statSync(RAW_FILE).size/1024).toFixed(1)} KB`);
   164→  }
   165→}
   166→
   167→// === Process ===
   168→const rawContent = readFileSync(RAW_FILE, 'utf8');
   169→const processed = {
   170→  run_id: RUN_ID,
   171→  run_ts: new Date().toISOString(),
   172→  scrape_summary: { /* ... */ },
   173→  // your aggregates, top-N, distributions, hashes, etc.
   174→};
   175→const processedJson = JSON.stringify(processed, null, 2);
   176→writeFileSync(PROCESSED_FILE, processedJson);
   177→
   178→// === Dump to log (log-as-output pattern) ===
   179→console.log(`========== PROCESSED_SUMMARY_START ==========`);
   180→console.log(processedJson);
   181→console.log(`========== PROCESSED_SUMMARY_END ==========`);
   182→
   183→// For full raw dump, stream it:
   184→import { createReadStream } from 'node:fs';
   185→import { createInterface } from 'node:readline';
   186→console.log(`========== RAW_DUMP_START ==========`);
   187→const rl = createInterface({ input: createReadStream(RAW_FILE), crlfDelay: Infinity });
   188→for await (const line of rl) process.stdout.write(line + '\n');
   189→console.log(`========== RAW_DUMP_END ==========`);
   190→
   191→console.log(`========== SCRAPE RUN ${RUN_ID} COMPLETED ==========`);
   192→console.log(`Total elapsed: ${((Date.now() - RUN_START) / 1000).toFixed(1)}s`);
   193→```

   195→### `plugins/store-data/index.js` (canonical template)
   196→```js
   197→import { readFileSync, existsSync, statSync } from 'node:fs';
   198→
   199→export default {
   200→  onPostBuild: async () => {
   201→    const RUN_TS = new Date().toISOString();
   202→    const KEY_TS = Date.now();
   203→    console.log(`========== STORE_PLUGIN started ${RUN_TS} ==========`);
   204→
   205→    const RAW_FILE = '/tmp/scrape-raw.jsonl';
   206→    const PROCESSED_FILE = '/tmp/scrape-processed.json';
   207→
   208→    if (!existsSync(RAW_FILE)) {
   209→      console.log('  No raw scrape data found');
   210→      return;
   211→    }
   212→
   213→    const rawContent = readFileSync(RAW_FILE, 'utf8');
   214→    const rawSize = statSync(RAW_FILE).size;
   215→    const processedContent = existsSync(PROCESSED_FILE)
   216→      ? readFileSync(PROCESSED_FILE, 'utf8')
   217→      : '{}';
   218→
   219→    console.log(`  Raw: ${(rawSize / 1024).toFixed(1)} KB`);
   220→    console.log(`  Processed: ${(processedContent.length / 1024).toFixed(1)} KB`);
   221→
   222→    try {
   223→      const { getStore } = await import('@netlify/blobs');
   224→      const store = getStore('scrapes');
   225→
   226→      // Write raw blob (large)
   227→      const rawStart = Date.now();
   228→      await store.set(`raw-${KEY_TS}.jsonl`, rawContent);
   229→      console.log(`  Raw blob written in ${Date.now() - rawStart}ms`);
   230→
   231→      // Write processed blob (small JSON)
   232→      const procStart = Date.now();
   233→      await store.setJSON(`processed-${KEY_TS}.json`, JSON.parse(processedContent));
   234→      console.log(`  Processed blob written in ${Date.now() - procStart}ms`);
   235→
   236→      // Write 'latest' pointer
   237→      await store.setJSON('latest', {
   238→        run_ts: RUN_TS,
   239→        run_unix_ts: KEY_TS,
   240→        raw_blob_key: `raw-${KEY_TS}.jsonl`,
   241→        processed_blob_key: `processed-${KEY_TS}.json`,
   242→        raw_size_bytes: rawSize,
   243→        processed_size_bytes: processedContent.length,
   244→      });
   245→      console.log(`  Latest pointer written`);
   246→
   247→      // List all blobs in store (auditable)
   248→      const list = await store.list();
   249→      const totalStoreBytes = (list.blobs || []).reduce((s, b) => s + (b.size || 0), 0);
   250→      console.log(`  Store contains ${list.blobs?.length || 0} blobs totaling ${(totalStoreBytes / 1024).toFixed(1)} KB`);
   251→
   252→      console.log(`  BLOB_WRITE_OK`);
   253→    } catch (e) {
   254→      console.log(`  BLOB_WRITE_ERR: ${e.message}`);
   255→      console.log(`  Stack: ${e.stack?.split('\n').slice(0, 6).join('\n')}`);
   256→    }
   257→
   258→    console.log(`========== STORE_PLUGIN_END ==========`);
   259→  }
   260→};
   261→```

   278→## How to Read Data Back (From Anywhere, 0 Credits)
   279→
   280→```bash
   281→# List all stores
   282→curl -s -H "Authorization: Bearer $TOKEN" \
   283→  "https://api.netlify.com/api/v1/blobs/$SITE_ID"
   284→# → {"stores":["site:scrapes","site:other-store"]}
   285→
   286→# List blobs in a store
   287→curl -s -H "Authorization: Bearer $TOKEN" \
   288→  "https://api.netlify.com/api/v1/blobs/$SITE_ID/site:scrapes"
   289→# → {"blobs":[{"key":"raw-123.jsonl","size":709536,"etag":"...","last_modified":"..."}]}
   290→
   291→# Read a blob (returns raw content)
   292→curl -s -H "Authorization: Bearer $TOKEN" \
   293→  "https://api.netlify.com/api/v1/blobs/$SITE_ID/site:scrapes/raw-123.jsonl" \
   294→  -o raw.jsonl
   295→
   296→# Read 'latest' pointer to find the most recent run
   297→curl -s -H "Authorization: Bearer $TOKEN" \
   298→  "https://api.netlify.com/api/v1/blobs/$SITE_ID/site:scrapes/latest" | jq .
   299→```
   300→
   301→**Verified:** 12+ MB of blob API read/write traffic consumed 0 credits. The blob API does not touch the bandwidth meter.

   303→## How to Write Blobs from Outside a Build (Direct API, 0 Credits)
   304→
   305→```bash
   306→# Step 1: Get presigned S3 URL by calling PUT with the signed-url accept header
   307→PRESIGNED=$(curl -s -X PUT "https://api.netlify.com/api/v1/blobs/$SITE_ID/site:my-store/my-file.json" \
   308→  -H "Authorization: Bearer $TOKEN" \
   309→  -H "Content-Type: application/octet-stream" \
   310→  -H "Accept: application/json;type=signed-url" \
   311→  --data-binary @local-file.json)
   312→
   313→S3_URL=$(echo "$PRESIGNED" | jq -r .url)
   314→# S3_URL looks like: https://cmh-services-prod-netliblob-XXX.s3.us-east-2.amazonaws.com/...
   315→
   316→# Step 2: Upload to S3 via the presigned URL
   317→curl -X PUT "$S3_URL" \
   318→  -H "Content-Type: application/octet-stream" \
   319→  --data-binary @local-file.json
   320→```
   321→
   322→**Verified:** 1.4 MB written this way = 0 credits.

   324→## Headless Chrome in the Build Process
   325→
   326→For scraping JS-rendered pages (SPAs, infinite scroll, login-required):
   327→
   328→```js
   329→// src/scrape.js — headless Chrome pattern
   330→import { execSync } from 'node:child_process';
   331→
   332→// Install Chromium binary at runtime (190 MB, ~2.5s)
   333→execSync('npm install @sparticuz/chromium --no-save', { stdio: 'inherit' });
   334→
   335→const { default: chromium } = await import('@sparticuz/chromium');
   336→const { default: puppeteer } = await import('puppeteer-core');
   337→
   338→const browser = await puppeteer.launch({
   339→  args: chromium.args,
   340→  defaultViewport: chromium.defaultViewport,
   341→  executablePath: await chromium.executablePath(),
   342→  headless: chromium.headless,
   343→});
   344→
   345→const page = await browser.newPage();
   346→await page.goto('https://example.com', { waitUntil: 'networkidle0' });
   347→const html = await page.content();
   348→const screenshot = await page.screenshot();
   349→
   350→await browser.close();
   351→```
   352→
   353→**Note:** `@sparticuz/chromium` and `puppeteer-core` must be installed in the build container, NOT bundled into a function (esbuild strips binary assets). For functions you'd need `node_bundler = "zisi"` instead — untested in this session.

   355→## Sane Throughput Limits (Empirically Validated)
   356→
   357→| Metric | Value |
   358→|---|---|
   359→| Build duration | Up to 15 min hard cap (Free). Tested: 289s successful; 20+ min stuck cancelled |
   360→| Concurrent builds | 1 (Free). Additional triggers queue |
   361→| Build memory | 4 GB |
   362→| Build disk | 9 GB free |
   363→| Single log chunk write | Tested 10 MB without truncation |
   364→| Total log per build | Estimate 50+ MB feasible |
   365→| Blobs per build | Tested 5 blobs in one build (700 KB + 7 KB + 200 bytes), no issue |
   366→| Outbound HTTP rate | Tested 4 req/s sustained for 5 min, no throttling |
   367→| Outbound HTTP endpoints | Tested httpbin, postman-echo, ipify, api.github.com (rate-limited shared IP), firebaseio (HN API) — all reachable |
   368→
   369→**Recommended max per build:**
   370→- 10-12 min runtime (safety margin under 15 min cap)
   371→- 5-10 MB raw data output to /tmp/ → Blobs
   372→- ~3,000 HTTP fetches (at 4 req/s self-throttled)
   373→- Hourly cron trigger (24 builds/day = 720/month, well within sane limits)
   374→
   375→**Per-month free throughput at hourly cron:**
   376→- 720 builds × 5 MB = ~3.6 GB fresh data written to Blobs
   377→- 720 builds × 10 min = 7,200 min of free compute (120 hours)
   378→- All at 0 credits

   380→## What Does NOT Work
   381→
   382→### Scheduled functions did not execute reliably
   383→- Function registered with `schedule: "*/5 * * * *"` correctly
   384→- `POST /api/v1/sites/{id}/functions/{name}/invoke` returns `HTTP 202 "triggered successfully"`
   385→- But no function ever wrote a heartbeat blob — function either didn't run or failed silently
   386→- Function-logs API requires Pro plan — couldn't see why
   387→- **Status: unverified. May be sandbox-specific or a real Free plan limitation.**
   388→
   389→### Multi-team free quota rotation
   390→- `POST /accounts` with Free `type_id` returns `422 "Account plan is unavailable to this user"`
   391→- Cannot create multiple Free teams under one account
   392→- The only multiplier is N distinct Netlify users (separate email + GitHub identity each)
   393→
   394→### Build hooks without Git
   395→- `POST /build_hooks/{id}` returns `HTTP 200` but doesn't trigger a build
   396→- Site must have a Git repo connected for build hooks to actually fire
   397→- Workaround: use `POST /sites/{id}/deploys` with `draft:true` + PAT (requires PAT, not anonymous)
   398→
   399→### Function URL access via direct curl
   400→- Account has `account_sso_login_context: "all"` hard-enforced
   401→- All URLs (including function URLs and static assets) return `HTTP 401` with redirect to `app.netlify.com/edge-access`
   402→- Cannot be disabled via API
   403→- **Impact:** Cannot invoke functions via anonymous HTTP — must use `POST /sites/{id}/functions/{name}/invoke` API endpoint with PAT (which itself only returns 202 fire-and-forget, doesn't give response body)
   404→- **Note:** This may be specific to GitHub-OAuth-only accounts without verified email. Real Netlify accounts may have public function URLs.

   406→## Polling Build Status
   407→
   408→While a build is running, you can poll `GET /api/v1/sites/{id}/deploys/{deploy_id}`:
   409→```json
   410→{
   411→  "state": "new",           // "new" | "ready" | "error"
   412→  "summary": {
   413→    "status": "building"    // "building" | "ready" | "unavailable" | "error"
   414→  },
   415→  "deploy_time": null       // seconds, populated when ready
   416→}
   417→```
   418→
   419→The actual build log content (your `console.log` output) is **NOT accessible via API until the build completes** — only the deploy state machine is queryable. To see logs, view them at `https://app.netlify.com/projects/{site}/deploys/{id}` in the browser (requires login).

   434→## When to Use Cloudflare Instead
   435→
   436→| Use case | Better tool | Why |
   437→|---|---|---|
   438→| High-volume HTTP API (100k req/day) | Cloudflare Workers Free | Dedicated daily quota vs Netlify's shared credit pool |
   439→| Object storage served to browsers | Cloudflare R2 Free | Zero egress + public URLs (Blobs has no public URLs) |
   440→| Relational DB with low-latency reads | Cloudflare D1 Free | No sleep, no compute charges |
   441→| I/O-bound serverless functions | Cloudflare Workers | CPU-time billing (not wall-clock) — 10-100× cheaper for I/O-bound code |
   442→| Cron-triggered scraping pipeline | **Netlify build process** | 15 min compute + Blobs storage = unbeatable free combo |
   443→| Headless Chrome scraping | **Netlify build process** | `@sparticuz/chromium` works in build container |
   444→| Multi-MB data dump storage | **Netlify Blobs** | Unmetered at-rest + free API reads |
   445→| Preview-environment DB branches | Netlify Database (Neon) | Per-deploy-preview DB branches |

   455→## Quick Reference: API Endpoints Used
   456→
   457→```bash
   458→# Account state (lag: 5-30 min on credits.used field)
   459→GET /api/v1/accounts
   460→GET /api/v1/accounts/{id}
   461→
   462→# Site management
   463→GET  /api/v1/sites?filter=all
   464→POST /api/v1/sites                    # Create site
   465→GET  /api/v1/sites/{id}
   466→DELETE /api/v1/sites/{id}
   467→
   468→# Deploys
   469→GET  /api/v1/sites/{id}/deploys
   470→POST /api/v1/sites/{id}/deploys       # Body: {"draft":true,"files":{...}} for preview
   471→GET  /api/v1/sites/{id}/deploys/{deploy_id}
   472→POST /api/v1/deploys/{id}/cancel       # Cancel stuck deploy
   473→PUT  /api/v1/deploys/{id}/files/{path} # Upload file content
   474→
   475→# Build hooks (require Git-connected site to fire)
   476→GET  /api/v1/sites/{id}/build_hooks
   477→POST /api/v1/sites/{id}/build_hooks
   478→DELETE /api/v1/sites/{id}/build_hooks/{hook_id}
   479→
   480→# Functions (invoke is fire-and-forget, async)
   481→GET  /api/v1/sites/{id}/functions
   482→POST /api/v1/sites/{id}/functions/{name}/invoke  # Returns 202
   483→
   484→# Blobs (REST API — works with user PAT for read + put)
   485→GET  /api/v1/blobs/{site_id}                        # List stores

   504→# Addendum: Functions as On-Demand HTTP Endpoints (Validated 2026-08-14T19:00Z)
   505→
   506→## The missing piece — function URLs CAN be public
   507→
   508→In the prior session, function URLs returned `HTTP 401` due to account-level SSO being hard-enforced. This is now SOLVED. The fix requires using the **internal bb-api** (Backend-For-Frontend) with **session cookies**, not the PAT.
   509→
   510→## Step 1: Disable SSO on the site (one-time setup per site)
   511→
   512→The official public API `PATCH /api/v1/sites/{id}` CANNOT disable SSO — the field returns `null`. You must use the internal bb-api.
   513→
   514→### Auth required
   515→- Session cookies from `app.netlify.com` (obtained by browser login)
   516→- Key cookies: `connect.sid` (Express session), `_nf-auth` (JWT, value starts with `nfu_`)
   517→- PAT (`nfp_...`) does NOT work for bb-api
   518→
   519→### The magic request
   520→```bash
   521→# Save cookies from browser DevTools after logging into app.netlify.com
   522→# (Application → Cookies → app.netlify.com → copy all cookie key=value pairs into one Cookie header)
   523→COOKIE_FILE=/path/to/cookies.txt
   524→SITE_ID=01ccde04-e779-41e6-89eb-57892acffaf2
   525→
   526→curl -X PUT \
   527→  "https://app.netlify.com/access-control/bb-api/api/v1/sites/$SITE_ID" \
   528→  -H "Content-Type: application/json" \
   529→  -H "Accept: */*" \
   530→  -H "Origin: https://app.netlify.com" \
   531→  -H "Referer: https://app.netlify.com/projects/$SITE_SLUG/" \
   532→  -H "Cookie: $(cat $COOKIE_FILE)" \
   533→  -d '{"password":"","password_context":"all","sso_login":false,"sso_login_context":"all"}'
   534→```
   535→
   536→**Critical:** `sso_login: false` (boolean) is what disables SSO. The `sso_login_context` stays `"all"` but is no-op once `sso_login` is `false`.
   537→
   538→### Response after success
   539→```json
   540→{
   541→  "sso_login": false,
   542→  "sso_login_context": "all",
   543→  "account_sso_login": false,
   544→  "has_password": false,
   545→  "password_context": "all"
   546→}
   547→```
   548→
   549→### Valid enum values for `sso_login_context`
   550→- `non_production` ✅ (previews public, prod private)
   551→- `all` ✅ (everything private — default)
   552→- `disabled`, `none`, `off`, `production_only` ❌ (422 error)
   553→
   554→### Account-level visibility (Free plan can't change)
   555→`PATCH /accounts/{id}` with `site_sso_login_context` returns `422 "Account is not eligible to update global access controls"`. Account-level visibility requires Pro plan. **But site-level fix is sufficient** — once `sso_login: false` is set on the site, all deploys become public.

   570→### `functions/scrape.js` — minimal on-demand HTTP proxy/scraper
   571→```js
   572→export async function handler(event, context) {
   573→  const targetUrl = event.queryStringParameters?.url;
   574→  const passthrough = event.queryStringParameters?.passthrough === '1';
   575→  const userAgent = event.queryStringParameters?.ua ||
   576→    'Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36';
   577→
   578→  if (!targetUrl) {
   579→    return {
   580→      statusCode: 400,
   581→      headers: { 'content-type': 'application/json' },
   582→      body: JSON.stringify({
   583→        error: 'missing url parameter',
   584→        usage: '?url=https://example.com[&passthrough=1][&ua=...]',
   585→      }),
   586→    };
   587→  }
   588→
   589→  const start = Date.now();
   590→  try {
   591→    const r = await fetch(targetUrl, {
   592→      method: event.httpMethod || 'GET',
   593→      headers: { 'User-Agent': userAgent, 'Accept': '*/*' },
   594→      redirect: 'follow',
   595→    });
   596→    const text = await r.text();
   597→    const elapsed = Date.now() - start;
   598→
   599→    if (passthrough) {
   600→      return {
   601→        statusCode: r.status,
   602→        headers: {
   603→          'content-type': r.headers.get('content-type') || 'text/plain',
   604→          'x-elapsed-ms': String(elapsed),
   605→        },
   606→        body: text,
   607→      };
   608→    }
   609→
   610→    return {
   611→      statusCode: 200,
   612→      headers: { 'content-type': 'application/json' },
   613→      body: JSON.stringify({
   614→        ok: r.ok,
   615→        status: r.status,
   616→        elapsed_ms: elapsed,
   617→        target_url: targetUrl,
   618→        response_size_bytes: text.length,
   619→        response_headers: Object.fromEntries(r.headers.entries()),
   620→        response_body: text,
   621→      }, null, 2),
   622→    };
   623→  } catch (e) {
   624→    return {
   625→      statusCode: 502,
   626→      headers: { 'content-type': 'application/json' },
   627→      body: JSON.stringify({ error: e.message, target_url: targetUrl }, null, 2),
   628→    };
   629→  }
   630→}
   631→```

   662→## TLS Fingerprint — Critical for Scraping Bot-Protected Sites
   663→
   664→### Default Node fetch = fingerprintable as bot
   665→When using `fetch()` in the function, the outbound TLS fingerprint is:
   666→
   667→| Metric | Value |
   668→|---|---|
   669→| JA3 hash | `1808993db60a053eb8ce0eb1c51750d6` |
   670→| JA4 | `t13d5212h1_b262b3658495_8e6e362c5eac` |
   671→| ALPN | `http/1.1` only |
   672→| Ciphers | 52 (Node's full list) |
   673→
   674→This is **instantly recognizable as Node.js/bot** by Cloudflare Bot Management, DataDome, PerimeterX. Will be blocked on protected sites.
   675→
   676→### Custom TLS via `node:tls` — partial fix
   677→You can override the cipher list and ALPN by using `tls.connect()` directly:
   678→
   679→```js
   680→import tls from 'node:tls';
   681→
   682→const CHROME_CIPHERS = [
   683→  'TLS_AES_128_GCM_SHA256',
   684→  'TLS_AES_256_GCM_SHA384',
   685→  'TLS_CHACHA20_POLY1305_SHA256',
   686→  'ECDHE-ECDSA-AES128-GCM-SHA256',
   687→  'ECDHE-RSA-AES128-GCM-SHA256',
   688→  'ECDHE-ECDSA-AES256-GCM-SHA384',
   689→  'ECDHE-RSA-AES256-GCM-SHA384',
   690→  'ECDHE-ECDSA-CHACHA20-POLY1305',
   691→  'ECDHE-RSA-CHACHA20-POLY1305',
   692→  // ... (Chrome's full cipher list)
   693→].join(':');
   694→
   695→const socket = tls.connect({
   696→  host: hostname,
   697→  port: 443,
   698→  servername: hostname,
   699→  ciphers: CHROME_CIPHERS,
   700→  honorCipherOrder: false,
   701→  minVersion: 'TLSv1.2',
   702→  maxVersion: 'TLSv1.3',
   703→  ALPNProtocols: ['h2', 'http/1.1'],
   704→});
   705→
   706→// Then send raw HTTP/1.1 request over the socket
   707→socket.write(`GET /path HTTP/1.1\r\nHost: ${hostname}\r\nUser-Agent: ${CHROME_UA}\r\nConnection: close\r\n\r\n`);
   708→```
   709→
   710→**Result:** JA3 hash changes from `1808993db60a053eb8ce0eb1c51750d6` → `ece2df6eaade0ed905954ae5663adcc5`, ALPN advertises h2. **But the extension list is still Node's default** (recognizable as Node).
   711→
   712→### What you need for true impersonation
   713→For full Chrome JA3/JA4 impersonation, the Node standard library can't do it. Use one of:
   714→- **`curl-impersonate`** binary (most accurate, must be installed in function via `node_bundler = "zisi"`)
   715→- **`got-scraping`** npm package (uses tls-client under the hood)
   716→- **`node-libcurl-impersonate`** npm package
   717→- **`@sparticuz/chromium` + puppeteer** (real Chrome TLS, but ~150MB, slow startup, needs `node_bundler = "zisi"`)
   718→
   719→### Practical guidance
   720→- **Scraping unprotected sites:** Use default `fetch()` — fast, simple, works fine
   721→- **Scraping JA3-aware sites:** Use `tls-impersonate` (see new section below) — Chrome-like JA3/JA4
   722→- **Scraping JA4-aware sites (Cloudflare Bot Management, DataDome):** `tls-impersonate` may work; for true impersonation use `@sparticuz/chromium` (real Chrome)
   723→- **Most sites don't check JA3** — default fetch is fine for ~90% of the web
   724→
   725→## TLS Impersonation with `tls-impersonate` (Verified Working)
   726→
   727→**`curl-cffi-node` does NOT work** — its native binary requires glibc 2.38 but AWS Lambda runtime has older glibc (2.26 or 2.34). **Use `tls-impersonate` instead** — pure JS, uses Node's `tls.SecureContext` API.

   759→
   760→### Function code (Chrome 120 impersonation)
   761→
   762→```js
   763→// functions/scrape.mjs
   764→import tls from 'node:tls';
   765→import { impersonate, isSupported } from 'tls-impersonate';
   766→
   767→export async function handler(event, context) {
   768→  if (!isSupported()) {
   769→    return { statusCode: 500, body: 'tls-impersonate not supported' };
   770→  }
   771→
   772→  const targetUrl = event.queryStringParameters?.url;
   773→  if (!targetUrl) return { statusCode: 400, body: 'missing url' };
   774→
   775→  // Chrome 120 ClientHello spec
   776→  const CHROME_SPEC = {
   777→    cipherSuites: [
   778→      0x1301, 0x1302, 0x1303,         // TLS 1.3
   779→      0xc02b, 0xc02f, 0xc02c, 0xc030, // ECDHE AES-GCM
   780→      0xcca9, 0xcca8,                 // ECDHE CHACHA20
   781→      0xc013, 0xc014,                 // Legacy ECDHE-SHA
   782→      0x009c, 0x009d, 0x002f, 0x0035, // Legacy RSA
   783→    ],
   784→    extensions: [
   785→      { type: 0x0016 }, // encrypt_then_mac
   786→      { type: 0x000b }, // ec_point_formats
   787→      { type: 0xff01 }, // renegotiation_info
   788→      { type: 0x0000 }, // server_name
   789→      { type: 0x0017 }, // extended_master_secret
   790→      { type: 0x000d }, // signature_algorithms
   791→      { type: 0x000a }, // supported_groups
   792→      { type: 0x0023 }, // session_ticket
   793→      { type: 0x0010, alpnProtocols: ['h2', 'http/1.1'] }, // ALPN
   794→      { type: 0x002b }, // supported_versions
   795→      { type: 0x002d }, // psk_key_exchange_modes
   796→      { type: 0x0033 }, // key_share
   797→      { type: 0x001c }, // record_size_limit
   798→      { type: 0x0015 }, // compress_certificate
   799→    ],
   800→    supportedGroups: [0x001d, 0x0017, 0x0018], // X25519, secp256r1, secp384r1
   801→    signatureAlgorithms: [0x0403, 0x0804, 0x0401, 0x0503, 0x0501, 0x0803, 0x0601, 0x0201],
   802→    alpnProtocols: ['h2', 'http/1.1'],
   803→  };
   804→
   805→  const { tlsOptions, unsupported } = impersonate(CHROME_SPEC);
   806→  // `unsupported` is an array of features tls-impersonate couldn't reproduce
   807→  // (typically 3 minor gaps: a sig algo, ec_point_formats content, padding extension)
   808→
   809→  const url = new URL(targetUrl);
   810→  const tlsSocket = tls.connect({
   811→    host: url.hostname,
   812→    port: 443,
   813→    servername: url.hostname,
   814→    ...tlsOptions,
   815→  });
   816→
   817→  await new Promise((resolve, reject) => {
   818→    tlsSocket.once('secureConnect', resolve);
   819→    tlsSocket.once('error', reject);
   820→    setTimeout(() => reject(new Error('TLS timeout')), 10000);
   821→  });
   822→
   823→  const path = (url.pathname || '/') + (url.search || '');
   824→  tlsSocket.write(
   825→    `GET ${path} HTTP/1.1\r\n` +
   826→    `Host: ${url.hostname}\r\n` +
   827→    `User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36\r\n` +
   828→    `Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8\r\n` +
   829→    `Accept-Language: en-US,en;q=0.9\r\n` +
   830→    `Connection: close\r\n\r\n`
   831→  );
   832→
   833→  const chunks = [];
   834→  await new Promise((resolve) => {
   835→    tlsSocket.on('data', (c) => chunks.push(c));
   836→    tlsSocket.on('end', resolve);
   837→    tlsSocket.on('close', resolve);
   838→    setTimeout(resolve, 8000);
   839→  });
   840→  tlsSocket.destroy();
   841→
   842→  const raw = Buffer.concat(chunks).toString('utf8');
   843→  const bodyStart = raw.indexOf('\r\n\r\n');
   844→  const headers = bodyStart >= 0 ? raw.substring(0, bodyStart) : '';
   845→  const body = bodyStart >= 0 ? raw.substring(bodyStart + 4) : raw;
   846→
   847→  return {
   848→    statusCode: 200,
   849→    headers: { 'content-type': 'application/json' },
   850→    body: JSON.stringify({
   851→      tls_protocol: tlsSocket.getProtocol(),
   852→      tls_cipher: tlsSocket.getCipher()?.name,
   853→      alpn: tlsSocket.alpnProtocol,
   854→      unsupported_features: unsupported,
   855→      response_status: parseInt(headers.match(/^HTTP\/[\d.]+ (\d+)/)?.[1] || '0'),
   856→      body_size: body.length,
   857→      body: body,
   858→    }),
   859→  };
   860→}
   861→```

  1128→
  1129→```js
  1130→export async function handler(event, context) {
  1131→  const targetUrl = event.queryStringParameters?.url;
  1132→  const r = await fetch(targetUrl);
  1133→  const body = await r.text();
  1134→
  1135→  // 1. WRITE LARGE DATA TO BLOBS (free, persistent)
  1136→  const { getStore } = await import('@netlify/blobs');
  1137→  const store = getStore('scrapes');
  1138→  const blobKey = `scrape-${Date.now()}`;
  1139→  await store.setJSON(blobKey, { url: targetUrl, body, ts: new Date().toISOString() });
  1140→  await store.setJSON('latest', { blob_key: blobKey });
  1141→
  1142→  // 2. LOG METADATA (free, 24h, structured)
  1143→  console.log(JSON.stringify({
  1144→    blob_key: blobKey,
  1145→    target_url: targetUrl,
  1146→    response_size: body.length,
  1147→    status: r.status,
  1148→    timestamp: new Date().toISOString(),
  1149→  }));
  1150→
  1151→  // 3. RETURN SMALL RESPONSE (pointer to blob, free)
  1152→  return {
  1153→    statusCode: 200,
  1154→    body: JSON.stringify({
  1155→      ok: true,
  1156→      blob_key: blobKey,  // Client fetches body via Blobs API
  1157→      size: body.length,
  1158→    }),
  1159→  };
  1160→}

  1212→# Addendum 4: Production Download Service + Proxy (Validated 2026-08-14T23:10Z)
  1213→
  1214→## Two production-grade services now in agent-kit
  1215→
  1216→### 1. Download Service (`functions/download.mjs` + `plugins/process-queue/index.js`)
  1217→
  1218→**Architecture:**
  1219→- Function handles queue submission, status queries, result retrieval, cancellation (fast operations)
  1220→- Build plugin (`process-queue`) handles actual downloading for async/long-running jobs (up to 15 min/cap)
  1221→- Sync mode (small files, <30s): function downloads inline
  1222→- Async mode (large files, >30s): function queues to blob, returns immediately, build plugin processes
  1223→
  1224→**Endpoints:**
  1225→```
  1226→POST   /api/download?url=<url>[&async=1][&method=fetch|chrome_impersonate][&ua=...][&timeout=N]
  1227→GET    /api/download?job_id=<id>
  1228→GET    /api/download?job_id=<id>&result=1     (raw bytes passthrough)
  1229→GET    /api/download?list=1[&status=pending|complete|error]
  1230→DELETE /api/download?job_id=<id>
  1231→```
  1232→
  1233→**State machine:**
  1234→```
  1235→pending → downloading → complete | error | cancelled
  1236→```
  1237→
  1238→**Storage layout** (Blobs, store=`download-jobs`):
  1239→- `queue/pending/{job_id}` — job spec (URL, method, UA, attempts)
  1240→- `status/{job_id}` — current status JSON
  1241→- `result/{job_id}` — raw downloaded bytes (with metadata)
  1242→- `index/latest` — pointer to most recent job
  1243→
  1244→**Retry logic:** Failed jobs retry up to 3 times (attempts counter incremented in queue blob). Stale `downloading` jobs (>10 min old) auto-requeue.
  1245→
  1246→**Long-running architecture:**
  1247→- 1 concurrent build on Free plan = serialized queue processing (no race conditions)
  1248→- Each build processes up to 50 jobs or until 14 min elapsed (1 min buffer under 15 min cap)
  1249→- GitHub Actions cron triggers preview deploys every N minutes → processes queue
  1250→
  1251→**Verified test results:**
  1252→- Sync mode: 5KB download in 109ms, blob stored, retrieved successfully
  1253→- Async mode: queued immediately (HTTP 202, 0.5s), processed by next build, status complete
  1254→- Chrome impersonate: JA3 hash `947eccbc4e2adea862cd37bf77342106` (Chrome-like)
  1255→- List endpoint: returns all jobs sorted by updated_at desc

  1300→## Critical: `external_node_modules` + `included_files` for native binaries
  1301→
  1302→To use `tls-impersonate` (or any package with native bindings) in a Netlify Function, you MUST:
  1303→
  1304→1. **Use `node_bundler = "zisi"`** (NOT esbuild — esbuild strips native binaries)
  1305→2. **Declare `external_node_modules = ["tls-impersonate"]`** in `netlify.toml [functions]`
  1306→3. **Declare `included_files = ["functions/node_modules/**"]`** so zisi includes the deps
  1307→4. **Install deps in `functions/` subdirectory** (not root) — `cd functions && npm install`
  1308→5. **Use `.mjs` extension** for ESM-only packages (tls-impersonate is ESM)
  1309→6. **Add `allowScripts` to `functions/package.json`** so native binary postinstall runs:
  1310→
  1311→```json
  1312→{
  1313→  "name": "functions",
  1314→  "version": "1.0.0",
  1315→  "type": "module",
  1316→  "dependencies": {
  1317→    "@netlify/blobs": "^8.0.0",
  1318→    "tls-impersonate": "^0.1.0"
  1319→  },
  1320→  "allowScripts": {
  1321→    "tls-impersonate": true
  1322→  }
  1323→}
  1324→```
  1325→
  1326→Without `allowScripts`, npm blocks the `node-gyp-build` postinstall script and the native binary doesn't get resolved.
  1327→
  1328→## Critical: Build plugin runs in onPostBuild (NOT build.command)
  1329→
  1330→The build command phase does NOT have `NETLIFY_BLOBS_CONTEXT` env var. Only the build plugin's `onPostBuild` hook has it. So:
  1331→- Don't try to write to Blobs from `build.command` (e.g., `node src/build-scraper.js` can't write to Blobs directly)
  1332→- Use a plugin's `onPostBuild` to read `/tmp/` files written by build.command, then write to Blobs
  1333→- Same applies for queue processing — `process-queue` plugin runs in `onPostBuild`
  1334→
  1335→```toml
  1336→# netlify.toml
  1337→[build]
  1338→  command = "node src/build-scraper.js"   # Writes to /tmp/, no Blobs access
  1339→  publish = "src"
  1340→
  1341→[[plugins]]
  1342→  package = "./plugins/store-data"   # Reads /tmp/, writes to Blobs in onPostBuild
  1343→```
