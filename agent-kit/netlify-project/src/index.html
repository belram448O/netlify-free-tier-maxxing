Netlify Free-Tier Scraper

This is a stub HTML page. The actual functionality lives in /functions/scrape.mjs.

Quick test

curl 'https://<deploy-id>--<your-site>.netlify.app/.netlify/functions/scrape?url=https://example.com&return_blob=1'

Endpoints

  • /.netlify/functions/scrape — on-demand scraper (default Node fetch)
  • /.netlify/functions/scrape?method=chrome_impersonate — uses tls-impersonate for Chrome-like JA3/JA4
  • /.netlify/functions/scrape?return_blob=1 — also writes scraped data to Blobs, returns blob key

Free-tier guarantees

  • Preview deploys = 0 credits
  • Blobs storage = unmetered (no at-rest cost, no API read/write cost)
  • Function-initiated downloads (ingress) = free
  • Function logs = free (24h retention, 4KB/invocation)
